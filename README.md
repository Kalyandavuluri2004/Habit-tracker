Habit Tracker Application

Overview
A Python-based command-line application to track daily habits and monitor progress using JSON storage.

Features
- Add new habits
- Track daily progress
- Maintain streak count
- Set goals for habits
- Delete habits
- Persistent storage using JSON

Technologies Used
- Python
- JSON
- Datetime module

How to Run
1. Install Python
2. Run the file:
   python habit_tracker.py

Project Structure
- habit_tracker.py
- habits.json

Purpose
This project demonstrates basic data handling, file management, and problem-solving using Python.
